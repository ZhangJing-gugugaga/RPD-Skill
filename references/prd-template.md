# PRD 模板

## 概念版 PRD（≤ 200 字）

核心用户：[一句话描述目标用户]
要解决的一件事：[一个具体痛点，不能写多个]
产品形态：[平台]
最小可用版功能（≤ 3 条）：
  1. [功能一]
  2. [功能二]
  3. [功能三]
本版本不做：[明确排除的功能]
商业模式：[收费方式 或 免费]
技术前提：[账号体系 / 数据方案 / 第三方依赖]

## 六大盲区自检清单

- [ ] **页面结构**：每个主要页面的职责、元素、不展示内容是否明确？
- [ ] **异常交互**：每个功能的用户流程是否包含异常路径？
- [ ] **状态机**：所有状态是否完整列出？进入和退出条件是否明确？
- [ ] **字段规范**：每个输入字段是否有类型、必填、长度、校验规则、错误提示？
- [ ] **文案规范**：空状态、加载、成功、失败、权限、网络异常六类文案是否齐全？
- [ ] **流程图**：用户流程是否包含分支和异常分支？

## 安全设计自检清单

> 以下清单覆盖 Vibe Coding 场景中最常见的安全盲区。每个功能模块都应逐项检查。

### 账户安全
- [ ] **短信/邮件验证**：是否有人机验证（图形验证码/滑块）？
- [ ] **频率限制**：单手机号/IP 每日发送上限是多少？
- [ ] **全局熔断**：是否有全局限频防止资源耗尽？

### 内容安全
- [ ] **UGC 审核**：用户头像、昵称、评论等内容是先审后发还是先发后审？
- [ ] **机审方案**：是否接入内容安全API（网易易盾/阿里云/腾讯天御）？
- [ ] **人工审核**：机审疑似案例的人工复核流程是什么？

### 文件安全
- [ ] **文件类型限制**：上传功能是否限制了允许的文件类型？
- [ ] **文件大小限制**：是否有单文件和总量限制？
- [ ] **存储方案**：使用云对象存储还是本地磁盘？
- [ ] **防盗链**：是否有 Referer/签名校验？

### AI 安全
- [ ] **Prompt 保护**：System Prompt 是否从代码中分离？
- [ ] **泄露防护**：是否有防角色扮演、防复述指令的措施？
- [ ] **模型信息**：是否暴露了底层模型名称/提供商？

### 传输安全
- [ ] **HTTPS**：全站是否强制 HTTPS？
- [ ] **敏感数据**：密码、token 是否加密传输？
- [ ] **CORS**：跨域策略是否正确配置？

### 基础设施安全
- [ ] **环境变量**：密钥是否通过环境变量注入，而非硬编码？
- [ ] **依赖审计**：是否有定期的依赖漏洞扫描？
- [ ] **日志脱敏**：日志中是否包含敏感信息？

自检通过后，输出："PRD 落地版已完成，六大盲区 + 安全设计均已覆盖。"
